# Kamakura Quant Lab

Kamakura Quant Labは、暗号資産市場の構造を再現できる記事と公開ツールで確認するためのプロジェクトです。ローソク足だけでは見えないスプレッド、約定、時間帯、取引所間の遅れを扱い、その検証に使える板・約定の過去データを提供します。

Kamakura Quant Lab is a reproducible market-structure project focused on order
books, trades and inspectable analysis workflows. Articles show what can be
measured, public tools make the workflow auditable, and paid data packages
provide historical cryptocurrency market data for deeper validation and
research.

## Repositories

| Repository | Role |
|---|---|
| Komachi | Customer-facing CLI for interacting with Yukinoshita and storing data in a DuckDB-ready bronze layout |
| Hase | Silver/gold analysis layer for deriving, inspecting and plotting order-book and trade data |
| Enoshima | Backtesting system and examples, published after cleanup |
| Yukinoshita | Data download API for token, grant and temporary URL handling |

## Path

```text
articles and reproducible examples
-> public tools
-> local order-book and trade analysis
-> historical data for deeper validation
```
