# Kamakura Quant Lab

Kamakura Quant Lab publishes reproducible market-structure research, open tools
for working with order books and trades, and historical cryptocurrency market
data.

The public repositories are built for inspection and reproduction. They show how
data is downloaded, how compatible free sources are arranged, and how
order-book and trade data can be analyzed locally.

## Repositories

| Repository | Role |
|---|---|
| Komachi | Customer-facing CLI for interacting with Yukinoshita and storing data in a DuckDB-ready bronze layout |
| Hase | Silver/gold analysis layer for deriving, inspecting and plotting order-book and trade data |
| Enoshima | Backtesting system and examples, published after cleanup |
| Kitakamakura | Data manager and publisher for verified historical market data |
| Yukinoshita | Data download API for token, grant and temporary URL handling |
| Tsurugaoka | Data download UI for buyer access |

## Path

```text
articles and reproducible examples
-> public tools
-> local order-book and trade analysis
-> historical data for deeper validation
```
